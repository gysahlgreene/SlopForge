# Hunyuan3D texture pipeline assessment

**Checked:** 2026-10-06. This is a source and license assessment, not legal advice. No model was downloaded, no environment was changed, and no texture inference was run.

## Decision

**Do not use Tencent Hunyuan3D 2.1 Paint for SlopForge generation or output handling in Ireland under the published community license.** Ireland is in the European Union, which the license explicitly excludes. The restriction covers using the model and using, displaying, or distributing its outputs outside the licensed territory. Running inference on a remote machine does not resolve the restriction if the work or output is then used in Ireland. Proceed only if Tencent grants separate written authorization or counsel confirms another applicable license.

The same territorial exclusion appears in the official Hunyuan3D 2.0 license, so downgrading to its texture pipeline is not a workaround.

## What the official pipeline does

The pinned [Hunyuan3D 2.1 repository](https://github.com/Tencent-Hunyuan/Hunyuan3D-2.1/tree/82920d643c0dc2f7bfd7255f45f62d386edfe60c) includes `hy3dpaint`, a texture-only route that accepts a mesh path and reference image. It renders/selects mesh views, conditions multiview PBR synthesis on rendered normals and positions plus the reference, bakes the generated albedo and metallic/roughness views into a UV atlas, inpaints uncovered texels, then saves an OBJ/GLB. The implementation is visible in [`textureGenPipeline.py`](https://github.com/Tencent-Hunyuan/Hunyuan3D-2.1/blob/82920d643c0dc2f7bfd7255f45f62d386edfe60c/hy3dpaint/textureGenPipeline.py), [`uvwrap_utils.py`](https://github.com/Tencent-Hunyuan/Hunyuan3D-2.1/blob/82920d643c0dc2f7bfd7255f45f62d386edfe60c/hy3dpaint/utils/uvwrap_utils.py), and the [Paint README](https://github.com/Tencent-Hunyuan/Hunyuan3D-2.1/blob/82920d643c0dc2f7bfd7255f45f62d386edfe60c/hy3dpaint/README.md).

The API defaults `use_remesh=True`; that path simplifies meshes above 40,000 faces. A fidelity experiment must explicitly set `use_remesh=False`, then check that output geometry and components are preserved. Even with remeshing disabled, the implementation generates/replaces UVs. Its save option downsamples texture maps, not mesh geometry.

Tencent documents 21 GB VRAM for texture generation at six views and 512 resolution. That fits the previously inspected 80 GB H100 in principle. However, the SlopForge H100 ComfyUI instance inspected for this audit has neither the Paint weights nor Paint nodes installed. The official route is a separate Python pipeline (Python 3.10, PyTorch 2.5.1 + CUDA 12.4 in the README) with custom CUDA rasterizer and differentiable-renderer compilation; it is not available through the current shape-only SlopForge ComfyUI graph. Keep any later evaluation isolated from ComfyUI.

## SlopForge recommendation

Technically, this is an unusually direct texture-only match for SlopForge’s existing Hunyuan v2 single-view mesh: it does not require regenerating the shape and can produce more complete PBR coverage than projecting the input image. Operationally it is not an available integration as installed, and legally the published terms block this Irish use. Keep it as a documented reference implementation only; do not add its code, weights, workflow, or outputs to SlopForge. Investigate a texture provider whose code, weights, and output terms explicitly permit the intended EU use. If authorization changes, run an isolated comparison on the same approved mesh/reference with remeshing disabled and inspect UV coverage, component/geometry preservation, materials, and Unity import before adoption.
