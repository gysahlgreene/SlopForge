# Character normalization qualification — 2026-10-06

All images are Blender 5.1 renders against the same source. The coarse result shows the previous resolution formula losing detail. The adjusted result retains the silhouette and suit features and remains below the 60,000-triangle budget, but its Rigify deformation is unacceptable. This is disposable qualification evidence, not an approved asset or production rig.

The original Hunyuan GLB and normalized mesh remain in the developer Downloads and temporary qualification project; neither is copied here. `manifest.json` records hashes, reports, and limitations.

The [`same-mesh-budget-skintokens`](same-mesh-budget-skintokens/) folder contains the same-mesh SkinTokens FBX, base-color bake, seven pose renders, contact sheet, and Blender report. The source normalization passes structural readiness. The rig is still experimental: the automated poses are not yet sufficient evidence of anatomically correct deformation, and Unity playback has not been run.
